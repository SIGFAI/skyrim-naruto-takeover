# Naruto Takeover

**Skyrim** × Naruto · visual · idea by the team

Bring Naruto into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Skyrim into a Naruto fan-fest: villagers poof into orange ninjas, shadow clones swarm bandits, and a Rasengan blasts the room.

## Install

Copy the contents of the release folder (Sigf.esp, Scripts, Textures, Meshes, Sound) into Skyrim Special Edition's Data folder and enable Sigf.esp. Start a game: the village turns into Naruto clones.
